# 微信表情包规范（执行版）

依据微信表情开放平台「制作规范 / 作品审核标准 / 投稿行为规范」整理。平台规则会调整，尺寸、体积等硬指标以上传页实时提示为准；本文件数值是**内控线**，通常比平台更严。

---

| --- | --- | --- | --- | --- | --- | --- | --- |
| 表情主图 | 聊天中发送 | 240×240 | 动态 GIF / 静态 PNG | ≤500KB | ≤400KB | 透明底 | 8 / 16 / 24 |
| 表情缩略图 | 面板与详情页预览 | 120×120 | PNG | ≤200KB | ≤100KB | 透明底，**禁止白描边** | 与主图 1:1 |
| 表情封面图 | 商店封面 | 240×240 | PNG | ≤500KB | ≤200KB | 透明底，**禁止白描边** | 1 |

| 详情页横幅 | 专辑详情页头图 | 750×400 | PNG / JPEG | ≤500KB | ≤300KB | 不透明，**禁纯白底、禁任何文字** | 1 |

补充：

- 张数只能是 **8、16、24**，不能是 9、12、20。
- 同一套**全静态或全动态**，不可混排。
- 动态主图必须永久循环，首尾帧不跳帧、无停顿黑帧。
- 主图与缩略图**编号一一对应**（01↔01），否则会串图。
- 缩略图 / 封面 / 图标要求无白描边，必须从**无描边版源文件**导出。

| 参数 | 建议 |
| --- | --- |
| 画布 | 480×480 或 960×960，导出缩到 240×240 |
| 帧数 | ≤24 帧（12–18 最稳） |

## 2. 画面规范

### 2.1 画布与安全区

- 交付 240×240；在 480 或 960 画布上做再等比缩小，避免锯齿。
- 角色主体占画面 **65%–80%**，四周留 ≥12px（240 画布下）安全区。
- 任何元素不得贴边、不得与边缘相切，否则聊天界面会被裁。
- 每张重心稳定，不要一张偏左一张偏右，面板里会「跳」。

### 2.2 描边

- 主图角色外轮廓加 **2px 纯白描边**，保证深色聊天背景也清晰。
- 只描外轮廓，不加在内部分割线和文字上。
- 缩略图 / 封面 / 图标不描白边。
- 抠图干净：无灰边、黑边、半透明残影、原背景色溢出。

### 2.3 文字

- 只用简体中文规范用字：无错别字、无生造词、正确使用「的 / 地 / 得」。
- 一套只用 1 种字体（最多 2 种），必须免费可商用：思源黑体、阿里巴巴普惠体、站酷快乐体 / 站酷高端黑、得意黑、霞鹜文楷。
- **禁用**：微软雅黑、苹方、汉仪 / 方正商业字库、影视字体包。
- 字号 ≤ 画面高度 1/5；文字总面积 ≤ 画面 1/3。
- 同套文字位置统一（统一底部或统一顶部）。
- 2–4 字最佳；白字 + 深描边，或深字 + 白描边。
- 不要长英文句、颜文字堆砌、二维码、网址、话题标签。

### 2.4 内容配比（16 张推荐）

打招呼 ×2、收到 / 好的 ×2、感谢 ×1、抱歉 ×1、开心 ×2、无语 / 嫌弃 ×2、疲惫 ×1、加油 ×1、晚安 ×1、拒绝 ×1、催促 ×1、庆祝 ×1。

- **每张表意必须不同**。仅改文字、动作高度相似的会被判重复。
- 只做「不用解释就懂」的通用情绪，不做圈内梗。
- 不指向具体职业、地域、性别、体型、疾病。

### 2.5 IP 一致性

- 开工前定角色卡：三视图、标准色值、线宽、五官比例、标志物、常用姿态。
- AI 生成时固定参考图、固定描述词、固定风格词。
- 不同套之间体型、主色、标志物不变，只换服装、道具、场景。
- 每套完成后与角色卡比一次，出现「变脸」整批返工。

### 2.6 装饰体系（三种模式共用）

**plain 模式**：不加任何装饰。要解决「太干」就改动作（歪头、耳朵角度、重心前倾），不要加符号。

**props 模式**分三层，总量压在 1/4 画面内：

1. **情绪符号**（每张 2–4 个）：开心→星星、纸屑；谢谢→爱心；无语→乌云、渐小的圆点、汗滴；晚安→月亮、星星。全部用与角色相同的粗线 + 平涂画法，不能是干净的矢量图标。
2. **小道具**（每张 1 件）：摆在脚边或身侧地面，与爪子留空隙，**爪子不握住、不捧着、不接触**。这一条是防「多一只手」的核心——角色一去抓东西，模型就会多画一条肢体。道具要比爪子略大，240px 下还能认形状；同套不重复。
3. **动势线**（按需）：点头、走路、雀跃时加 1–3 道短弧线，代替夸张动作，避免抬手。

配色：全套 ≤5 色（主色 + 奶油白 + 一个低饱和绿 + 少量点缀）。所有元素限制在画面中央 86%–88% 内。

**不要做**：给角色加项圈、围巾、帽子、眼镜、铃铛（容易画错，也锁死后续换季）；每张同一位置放同一挂饰（16 张会像同一张图）。

## 3. 文案字段

| 字段 | 限制 | 写法 |
| --- | --- | --- |
| 专辑名称 | ≤8 汉字，无标点空格 | IP 名 + 主题，如「喵庭小记·日常篇」；禁用「官方 / 正版 / 认证 / 微信」 |
| 专辑介绍 | ≤80 字 | 角色是谁 + 适合什么场景；不写联系方式、不导流、不蹭热点 |
| 版权信息 | ≤10 字 | IP 名称或作者名 |
| 表情含义词 | 每张 ≤4 汉字 | 写用户会搜的词（谢谢、无语、晚安），不写画面台词；同套不重复 |
| 分类 / 标签 | 按实际 | 选真实相符的分类，不堆热词 |

## 4. 内容红线（一票否决）

| 类别 | 禁止 |
| --- | --- |
| 版权 | 临摹、二改、拼接他人 IP；网络素材、素材站元素；AI 图含他人 IP 特征；未授权字体 |
| 肖像 | 真人、明星、公众人物、网红脸模；未成年人肖像 |
| 品牌 | Logo、商标、商品包装、门店、品牌配色暗示；暗示与腾讯 / 微信有关联 |
| 政治宗教 | 国旗国徽、政治人物、时政事件、宗教符号与元素、民族敏感内容 |
| 低俗暴力 | 色情暗示、暴露、脏话及谐音脏话、血腥恐怖、自残、暴力虐待 |
| 不良诱导 | 赌博、烟酒、毒品、酒驾、劝酒、未成年人模仿的危险行为 |
| 歧视 | 性别、地域、职业、种族、宗教、残障、性取向等歧视或丑化 |
| 导流 | 二维码、网址、微信号、公众号名、店铺名、电话、邮箱 |
| 虚假宣传 | 「官方」「正版」「认证」「第一」等背书词；夸大功效 |
| 蹭热点 | 灾难、事故、疫情、绯闻、丑闻、争议事件 |

免费表情允许「推广类」（不进商店展示但可搜索）；**付费与特效作品不得含任何推广性质**。

## 5. 高频驳回原因

1. 尺寸差 1px、格式不对、单张超体积。
2. 封面 / 图标不是透明底，或透明底带了白描边。
3. 缩略图、封面、图标残留白边、灰边、黑边。
4. 横幅纯白底或带文字。
5. 同套风格不统一（线宽、配色、画风、光影）。
6. 区分度不足：多张只换了文字。
7. 含义词重复或表意不清。
8. 文字错别字、生造词、字号压住角色。
9. 含 Logo、二维码、水印、网址、店铺信息。
10. 名称 / 介绍蹭热点人名或含「官方 / 正版 / 认证」。
11. 涉及名人、影视、动漫、游戏 IP。
12. 锯齿明显、边缘毛糙。
13. 驳回后不改就重提——判重复投稿，作品被锁定。
14. 与账号内已有作品相同或仅细节不同——同样判重复。

## 6. 提交流程

1. 登录 sticker.weixin.qq.com，创建专辑，选静态 / 动态。
2. 填名称、介绍、版权信息、分类、标签。
3. 按平台顺序上传：横幅 → 封面 → 图标 → 主图 + 缩略图（编号对应）→ 逐张填含义词。
4. 选免费 / 付费；设置是否开赞赏。
5. 提交审核，通常 5 个工作日内出结果。
6. 通过后必须手动点「上架」，否则搜不到。
7. 上架后每自然月仅可修改 1 次，改后重新排队。

### 开赞赏前置条件

艺术家资料审核通过；个人账号已绑定微信号；上传赞赏引导语 + 引导图 + 致谢图；账号无违规记录。

---

## 7. 违规代价

- 上架后判违规：强制下架 + 记违规 1 次。
- 累计 **3 次违规**：关闭赞赏与投稿能力 1 年。
- 驳回后原样重提，或与已有作品仅细节不同仍重提：判重复投稿，作品不能修改也不能再提交。
- 结论：被驳回先改再提；同一形象不要拆成多套近似作品反复投；宁少做，不重复。

## 8. 交付前自检

**技术项**

- [ ] 主图 240×240，数量 8 / 16 / 24，全同动或全同静
- [ ] 主图单张 ≤400KB
- [ ] 缩略图 120×120，数量与主图一致，编号对应
- [ ] 封面 240×240、图标 50×50，透明底且无白描边
- [ ] 横幅 750×400，非白底、无文字、不透明
- [ ] 赞赏引导图 750×560、致谢图 750×750（如开赞赏）
- [ ] 无 CMYK、无 16 位深度；PNG 透明通道正常，导入微信无黑底

**画面项**

- [ ] 角色不贴边，四周有安全区
- [ ] 主图有 2px 白描边，缩略图 / 封面 / 图标无白描边
- [ ] 抠图干净，无灰边、白边、原背景残留
- [ ] 整套线宽、配色、画风一致
- [ ] 每张动作构图差异明显，无雷同
- [ ] 文字清晰可读，字号不压角色

**合规项**

- [ ] 无第三方 IP、品牌、真人肖像
- [ ] 无二维码、水印、网址、联系方式
- [ ] 无政治、宗教、低俗、暴力、歧视内容
- [ ] 字体均免费可商用，已记录字体名
- [ ] 名称 / 介绍 / 含义词无「官方 / 正版 / 认证」
- [ ] AI 素材已人工复核，无他人 IP 特征残留

**文案项**

- [ ] 名称 ≤8 字，无标点，不重名
- [ ] 介绍 ≤80 字，无导流
- [ ] 含义词每张 ≤4 字，同套不重复
- [ ] 无错别字，「的 / 地 / 得」正确

## 9. 目录约定

```
<IP>-<专辑名>/
├─ 01_源文件/            角色卡、字体授权记录、1024 原图
├─ 02_导出/
│  ├─ main/01.png …      240×240 主图（带 2px 白边）
│  ├─ thumb/01.png …     120×120 缩略图（无白边）
│  ├─ cover.png          240×240 封面（透明、无白边）
│  ├─ icon.png           50×50 图标
│  ├─ banner.png         750×400 横幅
│  ├─ reward_guide.png   750×560
│  └─ reward_thanks.png  750×750
├─ 04_宣传图/            带专辑名的对外宣传图，不上传
└─ 03_投稿包/            按上传顺序整理，文件名与编号一致
```

两位数字编号，主图与缩略图同名（`01.png`），不用中文、空格、括号。
**带字的图一律放 04_宣传图**，详情页横幅、封面、图标禁止出现文字。
