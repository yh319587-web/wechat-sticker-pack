# 返工手册

按症状查。每条都是实际出图后踩过的坑，不是理论。

---

## 一、角色一致性

**每张长得都不太一样**
没带参考图，或参考图和提示词打架。
→ 必须走 `/v1/images/edits` 带图；提示词第一段只写「不可改变什么」，不要重新描述一遍五官细节，描述越多模型越自由发挥。

**越画越写实，毛茸茸的**
画风否定词不够。
→ 第 2 段补齐：粗深棕手绘线、水彩平涂大色块、有纸感、几乎不画毛发、不做体积光影、不做渐变高光；禁止写实 / 3D / 矢量 / 日漫 / 赛璐璐 / 数码厚涂。

**同套里有一张颜色明显发灰**
模型把浅色区画成灰调。
→ 动作句末尾加「纹路清晰、颜色饱和，不要把身体画得发白褪色」，单独重发这一张。不要整批重跑。

---

## 二、肢体

**多一只手 / 第三条前腿**
根因几乎都是「角色在拿东西」或「抬手做动作」。
→ 改构图，不改措辞：两只前爪并排落地、爪尖朝下；要表达动作就用身体重心、耳朵、尾巴和动势线，不要让爪子离地。道具挪到脚边，明确写「与爪子之间留出空隙，完全不接触」。

**爪子看起来像手指**
画了脚趾分割线。
→ 加「爪子是圆润的实心形状，不画脚趾分割线、不画指甲、不画肉垫纹路」。这条必须每张都在，漏一张就出问题。

**腿从肚子中间长出来**
坐姿描述不清。
→ 明确写「两条前腿从胸口自然垂下」「两条后腿在身体两侧」。

---

## 三、构图与裁切

**尾巴 / 耳朵 / 道具被画面边缘切掉**
主体太大或道具放太靠边。
→ 动作句加「完整收在画面内，不超出边缘」；导出脚本的 `fit` 参数把版心再收 6–10px。

**道具压在尾巴上**
位置描述没排他。
→ 写明方位与前后关系：「猫的右后方」「在猫身后偏一侧，不遮挡身体和尾巴」。

**每张重心不一样，面板里跳**
角色在画面中的落点不统一。
→ 导出时统一用角色 bbox 居中 + 固定顶边距，不要按画布居中裁。

**导出后四周安全区不足 12px**
`fit` 的版心太大。
→ 调 `style.fit_width` / `style.fit_height` 与 `style.top`，保证 bbox 距画布边 ≥12px（240 画布）。`check.py` 会打印最小边距。

## 四、表意

**本来是「无语」，出来像生气**
眉毛 / 嘴角 / 耳朵三处同时下压就会变愤怒。
→ 只压一处：眼睛画成两条水平短线，嘴角保持平直，耳朵只向后压一点点，不要皱眉。

**走姿含糊，看不出在走**
侧身角度不明确。
→ 写死左右：「左前爪抬起、右前爪落地，身体侧对观众，头转向观众」，再加动势线。

**遮住文字猜不出情绪**
动作差异不够。
→ 换眼睛形状是最快的办法；其次是耳朵角度（竖起 / 平放 / 后压 / 侧转）和尾巴走向（上扬 / 平伸 / 收拢 / 绕身）。

**16 张里有几张看着像同一张**
只换了道具，姿态没变。
→ 同套内姿态必须分散：正坐、侧身回头、趴、躺、站、跳各占一些。

## 五、缩略图与图标

**缩略图一团糊**
道具太小、细节太碎。
→ 道具放大到比爪子略大；删掉细碎元素（成串小花、密集纸屑）；缩略图从**无描边版**单独缩，不要缩主图。

**缩略图 / 封面 / 图标带白边**
直接缩了带白描边的主图。
→ 导出脚本里 `thumb`、`cover`、`icon` 都从 `base`（无描边）生成，`main` 才加描边。

**图标裁出来是半个身子或一片空白**
按比例硬裁。
→ 改成「取角色 bbox 顶部、水平居中、边长 = min(宽×0.62, 高×0.5)」，再用 `style.icon_zoom` 微调。

## 六、文字（带字方案）

**字距虚大，字和字之间空得离谱**
逐字渲染时每字都带投影或描边外扩，导致字身宽度虚高。
→ 先按 alpha bbox 裁掉透明边，再排字；投影整行加一次，不要逐字加。

**描边太粗把字糊了**
`stroke_width` 超过字号的 8%。
→ 240 画布下 42px 字用 3px 描边；68px 用 5–6px。宁细勿粗。

**加粗后字形崩了（横被拉宽、部首挤在一起）**
用仿粗体（重复描边）代替真实 Bold。
→ 换有真 Bold 的字重，或干脆不加粗，靠描边对比提亮。

---

## 七、横幅

**横幅上有字被驳回**
详情页横幅硬性禁止文字。
→ 投稿包里的 `banner.png` 必须无字。带标题的版本用 `scripts/banner_title.py` 另存到 `04_宣传图/`，只用于对外宣传。

**横幅是白底被驳回**
平台禁纯白 / 近白底。
→ 用奶油纸底（`#F9F0E0` 一类），加两三个模糊色斑，避免死板。

**750×400 直接生成总是变形**
模型对极端比例支持差。
→ 先生成 1536×1024（3:2），按 1.875 比例居中裁一条 1536×819 的带，再缩到 750×400。

---

## 八、流程

**一次改十几张，改完更乱**
→ 一次只改 1–3 张，`--only` 指定编号重发，其余不动。

**改完忘记哪张是新的**
→ `raw/` 保留全部原图，`--force` 会覆盖；改词前先把旧提示词复制一份到 `prompts/archive/`。

**导出后编号和缩略图错位**
→ 一律用两位数字文件名，主图与缩略图同名；`check.py` 会校验编号连续性。
