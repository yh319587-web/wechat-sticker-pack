# 提示词配方

`scripts/gen.py` 用同一套骨架拼每张的提示词。改词就改 `plan.json`，不要去改脚本。

## 骨架

六段固定 + 一段变化：

```
[1 角色]   严格以参考图中的 <角色> 为唯一外观依据：<不可变项>。不可改变品种、毛色、花纹分布、头身比例。
[2 画风]   画风必须严格复刻参考图：<线条/上色/质感>。禁止写实、3D、矢量、日漫、赛璐璐、数码厚涂、精细插画。
[3 解剖]   硬约束：只有一只角色 / 只有四条腿两条前腿两条后腿 / 爪子是实心圆角块 / 爪子不接触任何物品
[4 装饰]   plain：什么都不加。props：情绪符号 + 一件脚边道具 + 动势线，总量 ≤1/4 画面
[5 构图]   1:1、纯透明背景、角色占 55%、居中偏上、四爪与尾巴完整、无地面无投影无边框
[6 禁止]   禁止任何文字、字母、数字、标点、气泡、水印、签名、logo；不画第二个角色
[7 本张]   只画这一个动作与情绪：<action> + <symbol> + <prop>
```

顺序有讲究：**画风和解剖必须在动作之前**。动作写在最后，模型对「这一张要画什么」的注意力才不会被前面的长描述稀释。

## 第 3 段：解剖硬约束（防多手的关键）

默认按四足动物写，人形角色要整体替换：

```
一、画面中只有一只角色。
二、只有四条腿：两条前腿、两条后腿。任何姿势下都不能出现第三条前腿、第三只前爪或悬空的爪子。
三、坐姿时两条前腿从胸口自然垂下，两只前爪并排放在身前，爪尖朝下，不交叉、不叠放、不举高。
四、爪子是圆润的实心形状，不画脚趾分割线、不画指甲、不画肉垫纹路，避免看起来像手指。
五、耳朵、尾巴、四肢的连接位置必须正确，腿不能从肚子中间长出来。
六、爪子任何时候都不握住、不捧着、不接触任何物品。道具摆在身体旁边的地面上，与爪子留出空隙。
```

第 4 条最容易被忽略：**只要画出脚趾分割线，爪子立刻变手指**，后面怎么修都像人手。
第 6 条是防多手的根因处理：模型只要让角色「去拿」东西，就会多长一条肢体。

## 第 4 段：两种模式

### plain

```
装饰规则（本套为纯表情模式）：
一、画面中只有角色本身：不画道具、不画手持物、不画情绪符号、不画动势线、不画背景元素。
二、不佩戴任何配饰：不要项圈、围巾、帽子、眼镜、铃铛，也不要别花、别叶子。
三、不画地面、不画投影、不画边框、不画对话框。留白就是全部背景。
四、情绪只能靠五官与体态表达：眼睛形状、耳朵角度、重心、尾巴走向。
```

plain 模式出图「太干」是正常现象，处理方式是**改动作**，不是偷偷加装饰：

- 站得太正 → 改重心：前倾、后仰、歪一点。
- 表情不够 → 换眼睛形状（月牙 / 细线 / 半睁 / 两条横线）。
- 还是平 → 加耳朵角度和尾巴走向，这两处对情绪的帮助比加道具大。

### props

```
装饰规则（必须有装饰，但必须克制、统一）：
一、角色身上不佩戴任何配饰，角色就是干净的角色本身。
二、情绪符号：少量手绘水彩小元素烘托情绪，浮在周围，不接触身体，不遮挡脸。每个元素都要有粗深棕轮廓线，和角色同一种画法，不能是干净的矢量图标。
三、小道具：只画一件，摆在脚边的地面上，比爪子略大一点，与爪子之间留出空隙，绝不被爪子碰到。
四、整套只用三类颜色：<主色>、奶油白、低饱和橄榄绿，可加一点低饱和暖粉或雾蓝。不要高饱和荧光色。
五、装饰总面积不超过画面的四分之一，不能比角色更抢眼，留白仍然是主角。
六、所有元素限制在画面中央 88% 范围内，不能贴边被裁切。
```

## 第 7 段：动作词库

一句一个动作，**只写这一张**。句式：姿态 + 视线 + 眼睛 + 耳朵 + 尾巴 +（props）符号与道具位置。

### 打招呼
- 正坐面向观众，眼睛温和睁开，嘴角上扬，一只耳朵微微前倾，尾巴在身侧轻弯。
- 侧身回头，头转过来看观众，眼睛圆睁，两只耳朵朝前，尾巴翘起一小段。

### 收到 / 好的 / 答应
- 低头一点，下巴微收，眼睛半闭，耳朵平放，尾巴收在身侧。
- 端坐挺直，眼睛睁圆，耳朵竖直，一只前爪并排落地。
- 头轻歪向一侧，一只耳朵侧转，嘴角平直，尾巴末端轻抬。

### 感谢
- 眼睛弯成细线，头微微低下，两只耳朵向外张开，身体放松。

### 抱歉
- 头低下去，眼睛半闭下垂，两只耳朵完全耷拉，身体缩一点，尾巴贴住身侧。

### 开心 / 庆祝
- 眼睛弯成月牙，嘴角大幅上扬，两只耳朵竖起，身体挺直，尾巴向上卷。
- 微微跳起，四肢离地一点点，眼睛弯月牙，耳朵向后飘，身后两三道短弧线。

### 无语 / 嫌弃
- 正面端坐，眼睛画成两条水平短线，头微偏，一只耳朵向后压，嘴角平直。
- 半侧身，眼睛半睁，头略低，耳朵后压，尾巴甩向一侧。

### 疑惑
- 头明显歪向一侧，一只耳朵侧转，眼睛睁圆，另一只耳朵直立，尾巴停住不动。

### 困 / 累
- 坐着但身体塌下去，下巴快贴到胸口，眼睛半闭成一条缝，两只耳朵软软垂下，尾巴松垮地摊在身侧。
- 侧躺，头枕在前爪上，眼睛完全闭上，耳朵贴平，尾巴绕着身体。

### 加油
- 站起来，身体前倾，眼睛睁大，耳朵朝前，后腿蹬地，身后两三道动势线。
- 前爪并排踩地，胸口挺起，眼睛亮，嘴角上扬，耳朵竖直。

### 晚安
- 蜷成圆团睡着，眼睛闭合，耳朵放松，尾巴绕过来盖住身侧，头枕在爪子上。

### 拒绝
- 正面端坐，眼睛平静睁开，嘴角平直，两只耳朵竖直，身体不动，头轻微后仰。

### 催促
- 身体前倾，头抬起看向观众，眼睛睁大，耳朵朝前，尾巴在身后快速弯一下。

### 出门
- 侧身迈步，一只前爪抬起离地，头转回来看观众，耳朵朝前，尾巴上扬。

### 道具词库（props 专用，同套不重复）

纸风车、马克杯、小本子和铅笔、三角小旗、牛皮纸礼物盒、低头的小花、一颗带叶的小橘子、粗布小包裹、一片落叶、放大镜、揉皱的纸团、小喇叭、小枕头、一盆仙人掌、纸飞机、彩旗与纸屑、干花、小篮子、毛线球、信封、旧相机、玻璃弹珠、小风扇、雨伞。

道具写法必须带**位置 + 不接触**：

> 脚边右下角立着一个纸风车，插在一根细木棍上；风车与身体和尾巴之间要留出明显空隙，完全不接触。

## 修正语（重发时追加在动作句后面）

| 问题 | 追加 |
| --- | --- |
| 多一条腿 / 悬空爪 | 再次强调：只有四条腿，两条前腿并排落地，两条后腿在身侧，不出现任何多余的爪子。 |
| 爪子像手 | 爪子画成实心圆角块，不画任何脚趾线、指甲、肉垫纹路。 |
| 道具粘在爪子上 | 道具放远一点，摆在地面，与爪子之间留出一段空白，爪子不碰它。 |
| 尾巴被裁 | 尾巴完整收在画面内，不超出边缘。 |
| 走姿含糊 | 明确左右：左前爪抬起，右前爪落地，身体侧对观众，头转向观众。 |
| 脸发灰 / 褪色 | 虎斑纹路清晰、颜色饱和，不要把身体画得发白褪色。 |
| 表情看不出来 | 放大眼睛的形状差异：<指定形状>，并把耳朵与尾巴加上。 |
| 装饰过多 | 只保留两个符号和一件道具，其余留白。 |
| 画风跑偏 | 重申：粗深棕手绘线、水彩平涂、几乎不画毛发、不做体积光影。 |

## 参数建议

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `size` | 1024×1024 | 导出时缩到 240，留足重采样余量 |
| `quality` | high | 线条质量直接决定缩小后的清晰度 |
| `background` | transparent | 不支持时自动回退为白底，导出脚本会抠背景 |
| 并发 | 4 | 再高容易触发限流 |
| 重试 | 3 次，间隔 5s 起 | 超时与 5xx 都值得重试 |

## 出图后必须人工看的四件事

1. 腿的数量对不对，有没有悬空爪。
2. 爪子和道具之间有没有空隙。
3. 耳朵、尾巴、脚、道具有没有被边缘切掉。
4. 遮住文字，还能不能猜出这是哪个情绪。
