# 字体

脚本不内置字体文件（体积 + 授权记录清爽）。把字体放到本目录，或用 `--font` 指定路径。

## 推荐（均免费可商用）

| 用途 | 字体 | 授权 | 下载 |
| --- | --- | --- | --- |
| 表情上的台词 | 站酷快乐体 ZCOOL KuaiLe | SIL OFL 1.1 | https://fonts.google.com/specimen/ZCOOL+KuaiLe |
| 横幅副标题 / 正文 | 思源黑体 Noto Sans SC | SIL OFL 1.1 | https://fonts.google.com/noto/specimen/Noto+Sans+SC |
| 备选（更手写） | 站酷庆科黄油体 | 免费商用 | https://www.zcool.com.cn/special/zcoolfonts/ |

放好后：

```
assets/fonts/ZCOOLKuaiLe.ttf
assets/fonts/NotoSansSC-Bold.otf
```

## 禁止

微软雅黑、苹方、汉仪 / 方正商业字库、影视字体包——这些出现在投稿作品里会被判侵权。

一套只用一种字体（最多两种）。字体名记进 `01_源文件/字体授权记录.md`，审核被问到能立刻答上来。
